## 5a Rebirth erst nach Welt 2
Server blockiert (`err.rebirth_world2`), Button/Dialog zeigen den Hinweis (`ui.rebirth.locked_world2`). Inkubator-Upgrades hängen jetzt am vollständig geschafften Tower (I → Stufe 2, II → 3, III → 4) statt am Rebirth. Play-Test: vor Start geblockt, danach erlaubt. Test `rebirth_world2.test.lua` grün.
Gefundene Kopplungen an Rebirth, bewusst **nicht** geändert: Freischalt-Reihenfolge (`UNLOCK_AFTER`), `isEndlessOpen` (hängt an Final 100, nicht am Rebirth, ok), Boss-/Event-Skalierung, Login-Bonus-Multiplikator, Bestenliste „Rebirths“, Abzeichen R0 (versteckt). Tower-Deckel sind bereits fortschrittsbasiert (`TOWER_UNLOCK_BY_CLEAR`).

## 5b Kraftmodell V2
`PowerConfig`/`PowerRules`: Rarity-Basis +6 % pro Stufe, Wurf pro Bärchi aus uid (Verteilung zur Seltenheit hin geschoben), Note weak … outstanding, Anzeige „Wurf: … + HP/ATK/SPD/PWR“-Punkte im Bärchi-Panel. Bestandsschutz: Wurf mindestens 1 für Bärchis vor `LEGACY_CUTOFF_TIME`. Tower-Gegner werden skaliert (`TOWER_ENEMY_SCALE`).
Ziele erfüllt (Test): Top-15 % von Stufe N schlagen den Median von N+1/N+2; schlechtester N+2 > Median N−1. L50-Max-Common schafft Final 90–100, frisches L1 Common ≈ 2–3 Stages in Tower I.
**Wirkung auf Bestandsspieler:** V2 komprimiert hohe Seltenheiten stark (Omega deutlich schwächer als alt). Darum Standard aus; vor dem Einschalten Bestandsschutz-Konzept (Cutoff-Zeit) festlegen. Fusions-`baseStatOverride` wird unter V2 normalisiert.

## 5d Aufstiegs-Ei
Neues Pet `AscendantBaerchi` („Aufstiegs-Baerchi“, Godly, Skill `AscendingLight`, legt Aufstiegs-Eier alle 420 s), genau 1 % im Aufstiegs-Ei, in keinem anderen Ei. Kette: Aufstiegs-Ei braucht Welt 2 + Nebula-Bärchi; Transcendence → Aufstiegs-Bärchi; Eternity → Titan/Genesis; Omega → Chronos/Infinity. Selbstvermehrung begrenzt auf 0,086 Hoffnungs-Pets/h. Play-Test: `D:Invoke("dropchance","AscensionEgg")` zeigt AscendantBaerchi 1,000 %. Modell `Pet_Ascendant.fbx` gebaut, **Import in Studio steht aus** (zusammen mit Genesis, Infinity, Shade; danach `tools/pets/studio_recolor_w1.lua`).
